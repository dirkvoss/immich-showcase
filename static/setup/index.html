Frameside legt damit einmalig einen eigenen Schlüssel „Frameside (Dienst)“ ohne Lösch-Rechte an. Das Passwort wird nicht gespeichert.

Immich → Kontoeinstellungen → API-Schlüssel. Rechte siehe Anleitung; keine Lösch-Rechte für Fotos vergeben.
